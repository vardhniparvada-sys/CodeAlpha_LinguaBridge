# 🌍 LinguaBridge

### Smart Multilingual Language Translation Tool

LinguaBridge is a multilingual language translation web application developed using Python and Streamlit. It allows users to translate text between multiple languages through a simple and interactive interface.

## Features
- Supports 7 languages.
- Real-time text translation.
- Simple and user-friendly interface.
- Translation error handling.

## Languages Supported
- English
- Tamil
- Hindi
- French
- German
- Spanish
- Japanese

## Technologies Used
- Python
- Streamlit
- Requests
- Google Translate endpoint

## Installation

Install the required libraries:

    pip install -r requirements.txt

Run the application:

    streamlit run app.py
